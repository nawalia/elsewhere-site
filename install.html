Your iOS version

Pairing, two ways.

iOS 27 and later

On the iPhone itself

Settings, Privacy & Security, Developer Mode, "Pair with Elsewhere", type the code Elsewhere shows. No computer.

iOS 17 to 26

One time, from a Mac

These versions can't pair with themselves. Pair once on a Mac with the installer above (it includes the pairing tool), then open the pairing file in Elsewhere's Setup. After that the Mac is never needed.

Check yours in Settings, General, About, iOS Version. Elsewhere needs iOS 17.4 or later.

Known iOS snags, and the fix

If pairing fights you.

The Developer Mode switch disappeared, or pairing reset halfway

The screen locked or the flow was cancelled mid-way. Keep the iPhone unlocked and awake until pairing finishes, then start again from Elsewhere's Setup.

"Pairing complete", but nothing shows in Paired Devices

An older pairing with a Mac can block a new one on iOS 27. In Settings, Developer Mode, remove the old Mac pairing, then pair again.

Pairing times out on mobile data

iOS only offers new pairings over Wi-Fi. Join any Wi-Fi network for the pairing step; after that, mobile data is fine.

The place drops when the phone locks

Leave "Keep running in the background" on in Elsewhere's Settings, and allow Elsewhere's location access when asked, so iOS doesn't pause it.

Once it is installed

Setting it up.

About five minutes, once. Elsewhere checks each step for you.

  1. Developer Mode

    Settings, Privacy & Security, Developer Mode. The phone restarts once. Not a jailbreak, and you can turn it off.

  2. Pair with itself

    Elsewhere shows a code. Type it into Settings, Developer Mode, "Pair with Elsewhere".

  3. The connection

    Switch on the connection Elsewhere asks for. It loops the phone's connection back into itself and sends nothing to the internet.

  4. Pick a place

    Tap the map and press Set. Open Find My: you are there.

If something goes wrong

Fixes.

Setup says it cannot connect

The connection is almost always switched off. Check Settings, VPN. Only one VPN can be on at a time.

"Pair with Elsewhere" is missing in Settings

Developer Mode has to be on, and Elsewhere has to be open on its Setup screen while you look.

My real location came back

The phone restarted or the connection was switched off. Open Elsewhere and tap Set again.

Still stuck

Open Elsewhere, Settings, Help centre, Ask Nims, and say which step you are on. Or write to nanimswa@gmail.com.
